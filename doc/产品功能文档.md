## 1. 全局功能逻辑 (Global Functions)

### 1.1 适老化适配逻辑

* **功能描述**: 全局字体大小随用户设置动态变化。
* **逻辑规则**:
1. 应用启动时，从本地缓存或后端接口读取 `font_scale` 配置（默认为 1.0）。
2. 将 `font_scale` 注入全局 CSS 变量 `--font-scale`。
3. 所有涉及文本的组件，字号必须计算为 `base_size * --font-scale`。


* **倍率定义**:
* 标准: 1.0x (正文 16px)
* 大字: 1.2x (正文 19.2px)
* 特大: 1.4x (正文 22.4px)



### 1.2 权限控制 (Login Funnel)

* **游客模式**: 允许浏览首页、文章详情、视频流、圈子列表。
* **强登录触发点**:
* 点击“加入圈子”按钮。
* 点击“发布(+)”按钮。
* 点击“点赞”、“收藏”按钮。
* 点击“评论”输入框。
* 访问“我的”页面除“设置”外的功能。


* **交互表现**: 触发上述操作时，判断 Token 是否有效 -> 若无效，弹出 `AuthModal` 组件。

### 1.3 网络状态处理

* **断网**: 接口请求失败返回网络错误时，页面展示「无网络缺省页」，点击按钮重新加载当前页。
* **弱网 (4G/5G)**: 视频播放页检测到非 Wi-Fi 环境，且未授权过流量播放时，暂停视频并弹窗提示。

## 2. 核心模块功能详述

### 2.1 认证模块 (Authentication)

| 功能点 | 前置条件 | 输入/操作 | 系统处理逻辑 | 后置/输出 |
| --- | --- | --- | --- | --- |
| **微信一键登录** | 未登录 | 点击“微信登录”按钮 | 1. 调用 `wx.login` 换取 OpenID。<br>

<br>2. 后端查库：<br>

<br>- 有号：返回 Token。<br>

<br>- 无号：返回 `need_bind: true`。 | 登录成功 或 跳转手机绑定 |
| **手机号绑定** | 已获取 OpenID | 点击“手机号授权”或输入验证码 | 1. 校验手机号/验证码。<br>

<br>2. 写入数据库，关联 OpenID。<br>

<br>3. 颁发 Token。 | 登录成功，关闭弹窗，**自动继续用户刚才被打断的操作**。 |
| **退出登录** | 已登录 | 点击“设置-退出登录” | 1. 清除本地 Token。<br>

<br>2. 清除用户信息缓存。 | 跳转回首页，Toast提示“已退出”。 |

### 2.2 首页模块 (Home Feed)

| 功能点 | 交互逻辑 | 数据加载规则 | 异常处理 |
| --- | --- | --- | --- |
| **Tab 切换** | 点击推荐/附近/关注，内容区域横向滑动切换。 | 切换 Tab 时若无缓存则请求第一页；若有缓存则保留阅读位置。 | 列表为空展示缺省图。 |
| **下拉刷新** | 页面顶部下拉触发。 | 重置 `page=1`，请求最新数据，清空旧列表。 | 刷新失败 Toast 提示，保留旧数据。 |
| **上拉加载** | 滑动到底部距离 50px。 | `page + 1`，追加数据到列表尾部。 | 无更多数据显示 footer "没有更多了"。 |
| **资讯卡片** | 点击跳转文章详情页。 | 显示：标题、封面(懒加载)、浏览量、发布时间(如"3小时前")。 | 图片加载失败显示占位图。 |

### 2.3 内容浏览模块 (Content Viewer)

#### 2.3.1 文章详情

* **富文本渲染**: 解析 HTML 字符串，过滤 `<script>` 等危险标签。支持 `<img>` 点击大图预览。
* **字体调节悬浮窗**: 页面右下角常驻 `A` 按钮，点击展开滑块调节字号（仅影响当前页，不保存全局）。

#### 2.3.2 视频沉浸流

* **滑动切换**:
* 上滑：播放下一个。
* 下滑：播放上一个。
* **预加载**: 当前播放 Index 时，静默加载 Index+1 的封面和视频头 1MB。


* **双击点赞**:
* 双击屏幕任意位置 -> 播放点赞动画（爱心） -> 增加点赞数 -> 高亮侧边栏爱心图标。


* **播放控制**:
* 单击屏幕：暂停/播放切换，显示/隐藏中间的 Play 图标。
* 播放结束：默认循环播放。



### 2.4 圈子与发布模块 (Community & Publisher)

#### 2.4.1 加入/退出圈子

* **加入**: 点击“加入” -> 按钮变为“已加入” -> 更新本地状态 -> Toast “加入成功”。
* **退出**: 点击“已加入” -> **弹窗二次确认** “确定要退出吗？” -> 确认后变为“加入”。

#### 2.4.2 发布器 (Publisher)

* **媒体选择**:
* 图片：调用相册/相机，限制最多 9 张。支持预览、删除。
* 视频：限制 1 个，时长 < 3分钟，大小 < 200MB。


* **表单校验**:
* 标题：非空，Max 50字。
* 内容：Max 2000字。
* 圈子：必选（若从圈子页进入，默认选中当前圈子）。


* **发布动作**:
* 点击发布 -> 全屏 Loading "发布中..." -> 上传 OSS -> 提交后端接口 -> **成功后跳转回来源页并自动刷新列表**。



### 2.5 互动模块 (Interaction)

| 功能点 | 逻辑描述 |
| --- | --- |
| **点赞** | 乐观更新（点击即高亮 + 数字+1），后台异步请求。若请求失败，回滚状态并 Toast 报错。 |
| **评论** | 点击评论图标 -> 底部弹起输入框（自动聚焦）。<br>

<br>发送成功 -> 插入评论列表顶部（标记为"刚刚"）-> 滚动到该位置。 |
| **分享** | 点击分享 -> 唤起微信原生 Sheet。<br>

<br>- 好友：卡片形式。<br>

<br>- 朋友圈：生成海报图片（需 Canvas 绘制）。 |

### 2.6 个人中心模块 (User Profile)

* **我的发布**:
* Tab: 已发布 | 审核中/驳回。
* **状态展示**:
* 审核中: 卡片右上角灰色标签 "审核中"。
* 驳回: 红色标签 "未通过"，**点击卡片跳转到编辑页，并弹窗显示驳回原因**。




* **设置**:
* **字体大小设置**: 拖动滑块 -> 实时预览示例文本 -> 松手后保存配置并应用全局。

## 3. 数据埋点需求 (Tracking Requirements)

前端需在以下事件触发时调用 `uni.report()` 或自定义埋点 SDK：

1. **曝光事件 (Impression)**:
* `view_feed_card`: 资讯卡片出现在视口超过 500ms。
* `view_video`: 视频开始播放。


2. **点击事件 (Click)**:
* `click_tab`: 首页 Tab 切换 (参数: tab_name)。
* `click_publish_entry`: 点击发布入口 (参数: source_page)。


3. **业务结果 (Result)**:
* `publish_result`: 发布结果 (参数: success/fail, media_type)。
* `login_result`: 登录结果 (参数: method, success/fail)。

## 4. 边界与异常测试清单 (Edge Cases)

开发自测时需覆盖以下场景：

1. **超长文本**:
* 用户名超长：显示省略号。
* 文章标题超长：最多显示 2 行，超出省略。


2. **并发操作**:
* 快速多次点击“点赞”：防抖处理，只发送一次请求（或以最后一次状态为准）。
* 发布过程中断网：Loading 消失，提示“网络异常，请重试”，保留用户输入内容不丢失。


3. **空状态**:
* 搜索无结果。
* 我的收藏为空。
* 圈子内无帖子。


4. **账号异常**:
* Token 过期：接口返回 401，前端自动静默刷新 Token；若刷新失败，强制登出并跳转首页，重置用户状态。

## 5. 验收标准 (Acceptance Criteria)

1. **UI 还原度**: 与 Figma/蓝湖设计稿偏差 < 2px。
2. **适老化**: 在 1.4x 字体模式下，所有页面无遮挡、无重叠、无截断。
3. **性能**:
* 冷启动 < 1.5s。
* 视频页切换无明显黑屏。
* 列表滑动流畅 (FPS > 50)。


4. **功能**: 完成所有 P0 级用例（核心闭环）。
