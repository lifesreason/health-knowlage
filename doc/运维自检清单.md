# 运维自检清单（P2收尾版）

适用场景：本地联调、测试环境部署、生产发布后巡检。  
建议执行频率：每次发布后 + 每日巡检一次。

## 1. 配置与进程

1. 确认后端实际加载的是 `backend/.env`（不是 `.env.example`）。
2. 核对关键配置是否完整：
- 微信：`WX_APP_ID`、`WX_APP_SECRET`、`WX_LOGIN_MOCK_ENABLED`
- 短信：`SMS_PROVIDER`、`SMS_DAILY_LIMIT` 及对应云厂商参数
- Redis：`REDIS_HOST`、`REDIS_PORT`、`REDIS_PASSWORD`
- 缓存：`FEED_RECOMMEND_CACHE_TTL`
- 机审：`AUDIT_MACHINE_ENABLED/AUDIT_MACHINE_REVIEW_ENABLED`、`AUDIT_MACHINE_INTERVAL_MS/AUDIT_MACHINE_REVIEW_INTERVAL_MS`、`AUDIT_MACHINE_BATCH_SIZE`、`AUDIT_MACHINE_PROVIDER`
3. 启动日志无 DI 错误（如 `Nest can't resolve dependencies`）。

## 2. 数据库一致性

1. 库名与连接目标正确（避免连错容器/实例）。
2. 必要表存在：
- `rel_user_circle`
- `rel_user_follow`
- `biz_collect`
- `biz_user_history`
3. `biz_post` 关键字段存在：
- `collect_count`
- `lat`
- `lng`
4. 附近流索引存在：`idx_location (lat, lng)`。

## 3. Redis 与缓存

1. Redis 可连通（超时/拒绝连接需告警）。
2. 调用推荐流后检查：
- `GET /api/v1/stats/feed-cache` 返回 200（Admin Token）。
- 可带窗口参数：`GET /api/v1/stats/feed-cache?windowMinutes=10`
- 指标中 `requests` 增长、`hitRate` 有效（0~1）。
3. Redis 异常时服务仍可用（命中会降到 memory fallback）。

## 4. 机审链路

1. 发布新内容后确认进入待审（`audit_status=0`）。
2. 查询机审状态：
- `GET /api/v1/audit/machine/status`（Admin）
3. 手动触发一次消费：
- `POST /api/v1/audit/machine/run-once`（Admin）
4. 确认结果落库：
- `biz_post.audit_status` 更新
- `sys_audit_log` 写入日志
5. 可直接执行后端脚本：
- `cd backend && npm run smoke:audit`

## 5. 分享链路

1. 调用小程序码接口：
- `GET /api/v1/share/wxacode?scene=postId%3D123&page=pages%2Fdetail%2Fdetail`
2. 响应头检查：
- `Content-Type: image/png`
- `Cache-Control: public, max-age=300`
3. 前端海报生成成功（详情页、视频页）。

## 6. 认证与登录

1. 小程序登录接口可用：`POST /api/v1/auth/login`。
2. 微信异常时能返回上游错误码（不是统一吞成未知 500）。
3. `401` 场景前端能自动刷新 token 并重放请求。

## 7. 常见故障快速定位

1. 报表不存在/字段缺失：优先执行 `database/patches/20260212_schema_hotfix.sql`。
2. 仍报表不存在：核对后端 `.env` 指向的 DB 是否与执行补丁的 DB 同一个。
3. 微信登录失败：核对 `WX_APP_ID/WX_APP_SECRET` 与小程序环境是否匹配。
4. 短信失败：核对 `SMS_PROVIDER` 与对应厂商参数是否成套配置。
5. 机审异常重试：核对 `AUDIT_MACHINE_MAX_RETRY` 与 `GET /api/v1/audit/machine/status` 返回值是否符合预期。
6. 云厂商开通核对：参见 `doc/云侧机审开通核对表-阿里云腾讯云-2026-02-24.md`。

## 8. 评论审核链路

1. 评论提交后应返回 `auditStatus=0`（待审核）。
2. 管理员待审评论查询：`GET /api/v1/comment/admin/list?status=0`。
3. 管理员审核接口：
- 通过：`POST /api/v1/comment/admin/{id}/approve`
- 驳回：`POST /api/v1/comment/admin/{id}/reject`
4. 常见报错：
- 评论创建 500 且含外键报错时，执行 `database/patches/20260224_comment_audit.sql` 修复 `reply_to_user_id` 为空语义。
