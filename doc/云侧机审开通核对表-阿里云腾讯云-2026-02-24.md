# 云侧机审开通核对表（阿里云 + 腾讯云，2026-02-24）

## 1. 使用方式
1. 根据目标云厂商选择模板并合并到后端 `.env`：
- `backend/.env.audit.mock.example`
- `backend/.env.audit.aliyun.example`
- `backend/.env.audit.tencent.example`
2. 启动后端：`cd backend && npm run start`
3. 执行联调冒烟：`cd backend && npm run smoke:audit`

## 5. 风险与兜底
- 上游服务不可用时，系统应保持“人工复审可接管”的能力。
- 生产建议：`AUDIT_MACHINE_AUTO_REJECT=false` 先灰度，避免误杀。
- 建议为 `/api/v1/audit/machine/run-once` 与 Provider 异常日志配置告警。
